이차방정식 계산기

ax² + bx + c = 0 형태의 계수 a, b, c를 입력하면 판별식과 근을 바로 계산합니다.

계수 입력

근(x)
0

이차방정식 계산기 안내

💡이차방정식이란?

이차방정식은 ax² + bx + c = 0 (a≠0) 형태의 방정식입니다. 판별식(D = b² − 4ac)의 부호에 따라 근의 개수와 성질이 달라집니다 — D가 양수면 서로 다른 두 실근, 0이면 중근(실근 1개), 음수면 실근 없이 두 허근을 갖습니다.

🧮계산 방식

판별식

D = b² − 4ac

근의 공식

x = −b ± √D2a

📊판별식(D)에 따른 근의 성질

판별식근의 성질
D > 0서로 다른 두 실근
D = 0중근 (실근 1개, 겹치는 근)
D < 0실근 없음 (서로 다른 두 허근)

❓자주 묻는 질문

a가 0이면 왜 계산이 안 되나요?

a가 0이면 x²항이 사라져서 bx + c = 0 형태의 일차방정식이 되기 때문에, 이 계산기가 다루는 이차방정식의 정의를 벗어납니다.

허근(complex root)은 무슨 뜻인가요?

판별식이 음수면 근호 안이 음수가 되어 실수 범위에서 답이 없습니다. 이때 i(허수단위, i² = −1)를 사용해 x = 실수부 ± 허수부×i 형태로 근을 표현합니다.

인수분해로 풀 수 있는 방정식도 이 계산기로 풀 수 있나요?

네. 근의 공식은 인수분해가 되는 방정식이든 아니든 모든 이차방정식에 적용되는 일반해이므로, 어떤 계수를 넣어도 정확한 근을 구할 수 있습니다.
