최소공배수 계산기

두 개 이상의 자연수를 쉼표로 구분해 입력하면 최소공배수(LCM)를 바로 계산합니다.

값 입력

최소공배수
0

예: 4, 6, 8 처럼 쉼표(,)로 구분해 양의 정수를 입력하세요.

입력 즉시 자동 계산

계산 결과

--

최소공배수 계산기 안내

💡최소공배수(LCM)란?

최소공배수는 입력한 모든 수의 공통 배수 중 가장 작은 값입니다. 분수의 통분, 주기가 다른 일정을 맞추는 문제(예: 3일마다·4일마다 반복되는 일이 동시에 일어나는 날) 등에 쓰입니다.

🧮계산 방식

두 수의 최소공배수

LCM(a, b) = a × bGCD(a, b)

세 개 이상의 수

LCM(a, b, c, ...) = LCM(LCM(a, b), c), ... 순서로 반복 계산

📊계산 예시

입력최소공배수
4, 612
4, 6, 824
3, 5, 7 (서로소)105 (세 수의 곱과 동일)

❓자주 묻는 질문

서로소인 수들의 최소공배수는 어떻게 되나요?

공약수가 1밖에 없는 서로소 관계의 수들은 최소공배수가 모든 수를 곱한 값과 같습니다(예: 3과 5의 최소공배수는 15).

소수(1.5 같은)나 음수도 입력할 수 있나요?

최소공배수는 자연수(1 이상의 정수)에 대해서만 정의되는 개념이라 소수나 음수, 0은 입력할 수 없습니다.

숫자를 몇 개까지 입력할 수 있나요?

개수 제한은 없습니다. 쉼표로 구분해 원하는 만큼 입력하면 모든 수의 공통 최소공배수를 한 번에 계산합니다.
